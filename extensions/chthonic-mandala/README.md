# Chthonic Mandala Viewer

Sacred geometry visualization for the Chthonic Archive repository topology.

## Features

### Sacred Mandala Visualization
- **10,110 nodes** mapped from `topology_graph.json`
- **Concentric ring display** by PRISM band (RED → ORANGE → GOLD → BLUE → WHITE)
- **Golden ratio spiral** overlay (φ = 1.618033...)
- **FA¹⁻⁵ color mapping**:
  - FA¹ (Red): Alchemical transformation
  - FA² (Orange): Re-contextualization
  - FA³ (Gold): Qualitative transcendence
  - FA⁴ (Blue): Architectonic integrity
  - FA⁵ (White): Visual integrity

### Dependency Graph Navigator
- View `dependency_graph_production.json`
- File-level dependency mapping
- Ley line analysis (strongest connections)

### Health Report Panel
- Run `health_report.py` from webview
- Real-time repository diagnostics
- Cycle detection, orphan identification

## Commands

- `Chthonic: Open Sacred Mandala` - Main visualization
- `Chthonic: Open Dependency Graph` - File dependencies
- `Chthonic: Open Health Report` - Repository health

## Sidebar Views

Adds "Chthonic Geometry" activity bar icon with three tree views:
1. Sacred Mandala
2. Dependency Graph
3. Health Report

## Data Sources

Requires:
- `topology_graph.json` (generated by `scripts/mandala_topology.py`)
- `dependency_graph_production.json` (from DCRP)
- `health_report.py` (repository diagnostics)
