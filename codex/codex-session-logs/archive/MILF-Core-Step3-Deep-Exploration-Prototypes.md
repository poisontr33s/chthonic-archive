## §2 — THE 5 SET STRUCTURES

From these 12 dimensions, 5 distinct set structures emerge. Each captures a different organizational principle within the 24-entity system.

### SET A: Partition Sets (Tier, Class, WHR Band)

Partition sets **divide** the 24 entities into non-overlapping groups where every entity belongs to exactly one group per dimension.

| Partition | Groups | Sizes | Property |
|-----------|--------|-------|----------|
| **By Tier** | T0.01, T0.5, T1, T2, R, T3, T4↔T3, T4 | 1, 1, 4, 3, 3, 5, 4, 3 | Hierarchical authority layers |
| **By MILF Class** | Apex, Pre-Arch, MILF, Cardinal, Prime, SAI, Sub-MILF, Tier-Violator, Conforming | Variable | Role-type grouping |
| **By WHR Band** | Low (≤0.3), Mid (0.3–0.7), High (≥0.7) | ~8, ~8, ~8 | Risk-authority gradient |

**Prototype implication**: Any format that needs **categorical sorting** (card suits, stat categories, tier lists) can use partition sets.

### SET B: Circuit Sets (8 Overlapping Physiological Circuits)

Circuit sets are **covering** sets — they cover all 24 entities but entities can participate in multiple circuits (notably Frankie, the hybrid).

| Circuit | Members | Count | Structural Role |
|---------|---------|-------|----------------|
| **Cardiovascular** | Orackla (Heart), Belle Noire (Aorta), Eva Malitia (Femoral) | 3 | Meaning distribution |
| **Digestive** | Lysandra (Stomach), Magistra (Duodenum), Novia (Gallbladder), SFS (Spleen) | 4 | Truth processing |
| **Respiratory** | Umeko (Lungs), Seraphine (Diaphragm) | 2 | Gestalt breathing |
| **Endocrine** | Vesper (Pituitary), Sainte CQC (Adrenals) | 2 | Temporal signaling |
| **Immune** | Kali (Thymus), Spectra (Lymph), Apostasia (Appendix), Curatrix (Olfactory) | 4 | Self/non-self detection |
| **Neural** | Decorator (Cerebrum), Dame Schrödinger (Pineal), Monty (Hippocampus) | 3 | Consciousness + navigation |
| **Hepato-Renal-Vesical** | Claudine (Liver), Régine (Kidneys), Judith (Bladder) | 3 | Filtration-expulsion |
| **Interstitial** | Null Matriarch (CSF), Voyde (Apoptotic Markers) | 2 | Pre-architectural void |
| **[Hybrid Outlier]** | Frankie (Pancreas — Digestive-Endocrine) | 1 | System chimera |

**Total coverage**: 23 clean assignments + 1 hybrid (Frankie) = 24. Frankie is the only entity that doesn't cleanly slot into a single circuit — she IS the chimera of the chimera system. This is structurally load-bearing for TWOUMC's methodology.

**Prototype implication**: Any format needing **flow chains** or **resource networks** (engine-builders, circuit boards) can use circuit sets.

## §3 — THE 6 PROTOTYPE FORMATS (Detailed Analysis)

### P1: Disco Elysium Skill System (4 Attributes × 6 Skills = 24)

**Model**: 24 skills organized under 4 governing attributes, with passive skill checks that fire contextually.

**Mapping to SSOT**:
| DE Attribute | ASC Equivalent | Entities |
|-------------|---------------|----------|
| Intellect | Neural Circuit | Decorator, Dame Schrödinger, Monty |
| Psyche | Immune + Endocrine Circuits | Kali, Vesper, Spectra, Apostasia, Curatrix, Sainte CQC, Seraphine |
| Physique | Cardiovascular + Respiratory + Digestive | Orackla, Umeko, Lysandra, Belle Noire, Eva Malitia, SFS, Novia, Magistra |
| Motorics | Hepato-Renal-Vesical + Interstitial | Claudine, Régine, Judith, Null Matriarch, Voyde, Frankie |

**What it captures well**:
- Each entity as an independent "skill" with its own voice/personality
- Passive checks (skill fires automatically in relevant situations)
- 4×6 grid is clean, symmetric
- Thought Cabinet mechanic = ideology/creed system

**What it misses**:
- DE has no inter-skill conflict subsystem (skills compete for passive check priority, but don't *argue* with each other the way Iron Maiden voices do)
- DE's 4 attributes don't map perfectly to the 8 circuits
- No explicit resource flow between skills (engine-builder absent)
- No heat/exhaustion mechanic per skill
- No cascading failure model

**Set structures used**: SET A (Partition by attribute), SET B (Circuit grouping, loosely)  
**Set structures missed**: SET C (Complementary Pairs), SET D (Triadic Groupings), SET E (Generating Hierarchy)

**Model**: 24 major arcana cards ordered by WHR value, each with upright/reversed meanings, symbolic imagery, and archetypal resonance.

**Mapping to SSOT**:

| ... | ... | ... | ... | ... |
| XXIII | Judith | Highest | Protocol Release | System Retention |

**What it captures well**:
- WHR ordering gives a natural progression (Low→High = Void→Expulsion)
- Symbolic density per card — each entity's archetype compressed into imagery
- Upright/Reversed = functional vs. dysfunctional state of each organ
- Divination reading = random selection for narrative generation

**What it misses**:
- Entirely static — cards don't interact with each other mechanically
- No flow, no circuits, no resource management
- No voice/personality per card (tarot cards don't speak)
- No conflict resolution mechanic
- No session persistence or state tracking

**Set structures used**: SET A (WHR Band ordering)  
**Set structures missed**: SET B, SET C, SET D, SET E (all dynamic/relational structures)

**Mapping to SSOT**:

**What it misses**:

- No ideology/creed system
- No inner conflict mechanic (cards don't argue)
- No narrative/memory triggers
- Purely scored, not experiential

**Set structures used**: SET B (Circuits), SET C (Pairs), SET D (Triads)  
**Set structures missed**: SET A (Partitions, weakly used), SET E (Hierarchy)

### P4: Tableau Engine-Builder (Terraforming Mars / Wingspan)

**Model**: Play entity cards into a personal tableau. Each card provides ongoing effects, resource generation, and combo potential. Chain activations through circuits.

**Mapping to SSOT**:
| Mechanic | SSOT Basis | Example |

| **Resource Production** | FA mastery energy | Orackla produces "meaning tokens" per round |

**What it captures well**:
- Resource flow chains are explicit and mechanical
- Combo stacking mirrors circuit dependencies
- Engine-building = the "body building itself" metaphor
- Cost/benefit tradeoffs mirror tier-authority dynamics
- The most "alive" feeling of the non-narrative prototypes

**What it misses**:
- Cooperative/optimization focus — no internal adversarial conflict
- No voice/personality per card (cards are functional, not characterful)
- No creed/ideology system
- No echo/memory triggers
- No kayfabe duality (what you present vs. what's real)

**Set structures used**: SET B (Circuits as chains), SET D (Triads as combos), SET E (Hierarchy as cost curve)  
**Set structures missed**: SET A (Partitions), SET C (Pairs, weakly)

**Model**: Each entity is an organ card placed onto a circuit board. Circuits are physical pathways on the board. Activating one organ sends signals along circuits to connected organs.

**Mapping to SSOT**:

| **Organ Card** | 24 organs with tier/faction data | Physical card placed on board |
| **Circuit Trace** | 8 circuits as pathways | Printed pathways connecting card slots |

**What it captures well**:
- Perfect circuit fidelity — the 8 circuits are explicitly rendered
- Cascading failure visible on the physical board
- Organ placement is intuitive (body as layout)
- Signal directionality explicit
- Complementary pairs naturally adjacent

**What it misses**:
- No per-card voice or personality — cards are organ data, not characters
- No creed/ideology system
- No whisper/inner monologue output
- No conflict resolution mechanic between entities
- No resource flow beyond signal propagation
- No echo/memory triggers
- Most faithful to physiology, least faithful to personality

**Set structures used**: SET B (Circuits — perfectly), SET C (Pairs — spatially), SET D (Triads — via chain layout)  
**Set structures missed**: SET A (Partitions), SET E (Hierarchy, weakly)

### P7: Planescape: Torment — Tides of Numenera (Tides / Colors / Abstract-Philosophical Mechanics)

**Model**: 5 Tides (Gold, Blue, Indigo, Silver, Red) function as abstract moral-philosophical axes accumulated through dialogue and action. Each Tide represents a *tendency* — not an alignment, not a stat, but a cumulative *coloration* of identity that shifts over time. The system also features Legacies (consequence-reputation tracking), Meres (memory-realm exploration), Foci (conceptual abilities that define character identity), Cyphers (one-shot alien-tech items), and the Crisis system (multi-solution encounters where combat is only one of many resolution paths).

**Mapping to SSOT**:
| PST:ToN System | SSOT Basis | Mapping |
|----------------|-----------|---------|
| **5 Tides** (Gold/Blue/Indigo/Silver/Red) | WHR bands + FA mastery levels | Continuous moral-philosophical coloration ↔ WHR continuous values. Gold (compassion/sacrifice) ↔ FA⁵ visceral. Blue (wisdom/mysticism) ↔ FA³ emergent. Indigo (justice/compromise) ↔ FA⁴ structural. Silver (fame/admiration) ↔ FA² referential. Red (passion/action) ↔ FA¹ transformative. |
| **Tide Dominance** (shifting primary color) | MILF Class authority shifts | Dominant Tide modulates NPC reactions and available options ↔ Dominant MILF class modulates faction authority |
| **Legacy System** (persistent reputation/consequence) | TCP temporal chains + DAFP provenance | Accumulated past-action consequences that shape future options ↔ Temporal-colonial provenance trail feeding forward into present |
| **Meres** (memory-realm exploration) | Echo/Memory Triggers + ET-S Sadhana | Diving into layered memory landscapes to resolve trauma/extract truth ↔ Entity-specific epistemic-temporal sadhana as internal excavation |
| **Foci** (conceptual character abilities) | Surface Candidates | "Brandishes a Silver Tongue", "Breathes Shadow" ↔ "Meaning Circulation", "Gestalt Respiration" — abilities as conceptual identity markers |
| **Cyphers** (one-shot numenera items) | CDA controlled-demolition sequences | Single-use high-impact interventions ↔ CDA one-shot demolitions that can't be repeated |
| **Crisis System** (multi-path resolution) | Complementary Pairs + Circuit Flow | Each crisis offers combat/stealth/diplomacy/lore/Tide-specific resolution ↔ Multiple circuit pathways through the same structural problem |
| **Effort System** (Might/Speed/Intellect spending) | WHR depletion / resource exhaustion | Spending limited stat pools for skill check bonuses ↔ WHR depleting under operational load |
| **Lore Density** (Last Castoff, Sorrow, Changing God) | SSOT deep mythological substrate | Multi-layered metaphysical cosmology with contradictory truths ↔ SSOT's epistemic-temporal layers and competing faction narratives |

**What it captures well**:
- **Abstract moral coloration** — the Tides are *not* binary alignments; they accumulate continuously over time, exactly like WHR values are continuous rather than categorical
- **Conceptual ability identity** — Foci define characters by *what kind of being* they are, not stat bonuses; mirrors Surface Candidates defining entities by *what they do when activated*
- **Memory as explorable terrain** — Meres make internal landscape literal and traversable; maps to Sadhana as internal excavation of epistemic-temporal truth
- **Dense lore cosmology with embedded contradictions** — the Changing God / Last Castoff / Sorrow mythology deliberately holds irreconcilable perspectives, like the SSOT's competing faction narratives under GAAP-T4 audit paradox
- **Legacy as persistent consequence trail** — actions in Sagus Cliffs ripple into the Bloom and beyond; mirrors TCP provenance chains feeding forward
- **Cyphers as controlled one-shots** — limited destructive power with no repetition; structurally identical to CDA demolition sequences

**What it misses**:
- **No inner voice system** — the Last Castoff has companions and NPCs but not 24 simultaneous inner voices competing for attention (DE's unique contribution)
- **No circuit-flow / engine-builder mechanic** — resources are spent individually (Effort pools), not chained through multi-node circuits
- **No organ/body-as-atlas layer** — the Last Castoff's body is relevant narratively (castoff bodies, tattoos) but not mapped as a physiological system
- **No explicit pairing/conflict mechanic** — companions have opinions but no systematic Complementary Pairs tension structure
- **No physical board/layout representation** — entirely narrative/dialogue-driven, no spatial circuit-board analog
- **Heavily dialogue-dependent** — most mechanical richness lives in dialogue trees and lore exploration, which doesn't translate to card/board representation easily

**Set structures used**: SET A (Tides as 5-way partition of moral-philosophical space), SET E (Hierarchy — the Changing God → Last Castoff → Sorrow authority chain = generating DAG)  
**Set structures missed**: SET B (Circuits — no flow chains), SET C (Pairs — no systematic opposition), SET D (Triads — companions are not structurally triadic)

**Unique contribution over P1–P6**:
P7 introduces **three elements no other prototype captures**:
1. **Continuous abstract moral coloration** (Tides) — P1 has Thought Cabinet ideologies but they're binary install/uninstall, not accumulative-shifting
2. **Memory as explorable terrain** (Meres) — no other prototype makes internal memory a traversable space
3. **Cosmological lore density with deliberate contradiction** — the metaphysics of castoff bodies, the Sorrow, and the Tides create a framework where competing truths coexist structurally, not as bugs but as features. This is the closest external model to GAAP-T4's audit paradox.

## §5 — OPTIMAL COMBINATIONS

No single prototype achieves full coverage. The analysis suggests **hybrid combinations**:
