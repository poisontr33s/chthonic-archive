**Technical facts:**

### Epoch 10 — Format-Aware Model Discovery (Feb 27)

**What happened:** User challenged: "How do we know what is the best format? Wouldn't that need actual research?" Mapped all 20 mistral.rs v0.7.0 supported architectures from CLI error enumeration. Built `scripts/hf_model_scout.py` (643 lines): architecture-aware HF discovery, 15 regex patterns, parallel API fetch. Format research from official docs: ISQ, GGUF, UQFF, GPTQ, FP8, imatrix. Key finding: imatrix brings ISQ to GGUF parity; UQFF = ISQ saved to disk. Upgraded scout with format intelligence: UQFF > GPTQ > ISQ > GGUF hierarchy. KNOWN_UQFF registry (15 EricB models), GPTQ variant probing, smart quant selection. Fixed safetensors false negatives via file siblings fallback.

**Key artifacts:**
- `scripts/hf_model_scout.py` (643 lines)
- Scout integrated as `manager scout` subcommand
- Format hierarchy: UQFF > GPTQ > ISQ-auto > GGUF
- `KNOWN_UQFF` registry (15 EricB models)
- `QUANT_PROFILES`, `ARCH_PATTERNS` (15), `HF_CONFIG_ARCH_MAP`

**Lessons:** Format selection drastically affects quality and load time. Research-first approach validated: don't guess formats, map the hierarchy. UQFF (ISQ persisted to disk) is the optimal format when available. GPTQ has Marlin kernel acceleration on CUDA. imatrix calibration is the missing link for ISQ quality.
