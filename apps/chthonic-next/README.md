# chthonic-next

Bun-native Next.js + React + Tailwind lane for Chthonic Archive.

## Bun doc alignment

- Next.js with Bun runtime scripts: https://bun.com/docs/guides/ecosystem/nextjs
- React with Bun: https://bun.com/docs/guides/ecosystem/react
- Tailwind in Bun fullstack bundler lanes: https://bun.com/docs/bundler/fullstack#tailwindcss-plugin

## Commands

```bash
bun run dev
bun run build
bun run start
bun run typecheck
```

## Notes

- This app is intentionally separated from VS Code extension host runtime.
- It is the fast frontend lane for dashboards, telemetry UX, and experimental interfaces.
