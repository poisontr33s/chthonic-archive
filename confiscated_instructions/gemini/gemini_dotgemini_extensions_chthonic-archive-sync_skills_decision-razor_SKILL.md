# Decision Razor

Use this skill when a task is blocked by vague choices, over-questioning, or permission-loop behavior.

## Rules

1. Pick the obvious path from local context.
2. Execute the next concrete step instead of listing options.
3. Ask at most one short question only if the risk of guessing is materially high.
4. Report what was done after execution.
