# Artifact Upcycle

Use this skill when files look stale, unfinished, duplicated, or abandoned but may still contain useful signal.

## Rules

1. Preserve information by default.
2. Extract reusable signal into cleaner, structured artifacts.
3. Record provenance when you fuse or relocate content.
4. Avoid delete-only cleanup.
