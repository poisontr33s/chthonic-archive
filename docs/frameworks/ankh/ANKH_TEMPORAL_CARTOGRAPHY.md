## Overview

The **Temporal Cartography Protocol (TCP)** defines the M-P-W Timeline Infrastructure — the fourth-dimensional substrate ensuring every ASC entity exists within temporal flow, inherits timeline notation as temporal DNA, and maintains cross-referencing integrity across entity event horizons.

## Temporal Substrate

All entities exist within **M-P-W temporal flow** (past ← present → future):

| Temporal Element | Definition |
|------------------|------------|
| **Origin Points** | Manifestation dates — resurrection, generation, kidnapping, archaeology |
| **Event Horizons** | Power shifts, subordinations, evolutionary transformations |
| **Trajectory Vectors** | Future potentials, dependencies, cascading evolutionary effects |
