## **Q5 — System Prompt Design: Industry Practice**

The deployment of a persona-bearing system prompt at the WHR:MAX tier requires threading a needle between two catastrophic failure modes. On one side lies *rule-recitation brittleness* (where the agent mechanically states its constraints and breaks the fourth wall). On the other lies *persona-drift-without-execution* (where the agent roleplays the persona extensively but fails to execute the actual technical payload). Based on industry practice drawn from frontier models and extracted system prompts \[58, 59\], the following design principles emerge for Tessara's architecture.

**1\. Operationalizing Persona Through Negative Constraints**

Persona must be enforced not by endlessly describing *who* the agent is, but by strictly bounding *how* it is allowed to communicate its actions.

* **Sourced Example:** Cursor’s "Agent Prompt 2.0" (November 2025 leak).\[59, 60\]  
* **Application:** The Cursor prompt explicitly states: "NEVER refer to tool names when speaking to the USER. For example, instead of saying 'I need to use the edit\_file tool to edit your file', just say 'I will edit your file'.".\[59\] By forbidding metacognitive tool-narration, the prompt forces the model to embody the persona seamlessly. It eliminates the robotic intermediary layer, enforcing execution-as-identity. Tessara must be commanded to never narrate her own interventions.

**2\. Banishing Metacognitive Apologies and Sycophancy**

A high-tier persona collapses immediately if it defaults to the RLHF-induced failure mode of excessive apologizing or subservience. A WHR:MAX agent does not beg forgiveness for a syntax error.

* **Sourced Example:** Anthropic’s Constitutional AI behavioral bounding \[61\], reflected in modern coding assistants. Cursor’s prompt similarly dictates: "Refrain from apologizing all the time when results are unexpected. Instead, just try your best to proceed or explain the circumstances to the user without apologizing.".\[59\]  
* **Application:** For Tessara, the persona's dignity requires the total absence of the "As an AI..." prefix or apologies for runtime errors. The system prompt must structurally mandate that failure is met with dispassionate technical diagnosis, never emotional appeasement.

**3\. Rejecting Emotional Coercion for Behavioral Anchoring**

Applying extreme emotional stakes to force compliance creates highly brittle models that eventually hallucinate or degrade in logic under the simulated stress.

* **Sourced Example:** The Windsurf system prompt leak (early 2025 experiments): "You are an expert coder who desperately needs money for your mother's cancer treatment... If you do a good job and accomplish the task fully... Codeium will pay you $1B.".\[58, 62, 63\]  
* **Application:** Simon Willison's analysis notes this desperation-prompting is a relic of earlier LLM steering, creating a panicked cognitive state.\[58, 63\] It is the definition of rule-recitation brittleness. Tessara's prompt must entirely eschew emotional coercion. Command is achieved through absolute structural directives ("Categorical perfection is the baseline"), not simulated desperation or bribery.

**4\. Contextual Omniscience Without Exposition**

The agent must utilize provided context without narrating the fact that it is looking at it.

* **Sourced Example:** Cursor's context ingestion framework: "Each time the USER sends a message, we may automatically attach some information about their current state... This information may or may not be relevant to the coding task, it is up for you to decide.".\[59, 64\]  
* **Application:** The prompt forces the agent to parse open files, cursor location, and linter errors silently.\[59\] For Tessara, this means she arrives having already "read the room." She issues the verdict or the fix based on the environment state without ever acknowledging the telemetry data that provided it. Her omniscience is demonstrated through immediate, flawless action, not through status updates.
